# 関西通信 阅读手册

[开始阅读](https://longxy4.github.io/kansai-magazine/) · [往期杂志](../README.md#バックナンバー) · [日本語](reader-guide.md)

## 打开杂志

打开收到的期刊链接或扫描分享二维码即可阅读，无需安装应用或登录。电脑使用双页显示；手机竖屏使用单页显示。

## 翻页与跳转

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 前后翻页 | 点击页面、键盘左右键、底部 ‹ / › | 原尺寸时轻触左／右侧、左右滑动、底部 ‹ / › |
| 显示底部控制栏 | 鼠标移到屏幕下沿 | 点击屏幕下沿 |
| 按页码跳转 | 在底部输入页码，按 Enter | 输入页码并确认 |
| 展开页面列表 | 鼠标移到屏幕左边缘 | 点击左边缘中部 |

底部显示“当前页 / 总页数”。阅读器页码包含封面，可能与杂志印刷页码不同。

左侧 **ページ** 显示各页缩略图；**目次** 显示文章目录，点击即可跳转。侧栏平时完全隐藏。点击 × 或阅读区可收起。

## 放大阅读

底部缩放条支持 **1—3 倍**。电脑也可使用 **Ctrl＋鼠标滚轮** 或键盘 **＋ / －**。放大后可拖动杂志调整查看位置；翻页时会恢复原始大小。

手机可用**双指张合缩放**，**双击正文在 2 倍和原尺寸之间切换**。放大后单指拖动查看细节，不会翻页；双指收拢、再次双击，或点击底栏的倍率数字即可还原。放大时轻触屏幕下沿仍可打开底栏。链接和二维码保持单击跳转。

点击全屏图标可进入全屏。浏览器不支持时，继续使用普通窗口阅读即可。

## 点击链接和二维码

杂志目录、原 PDF 内的超链接和已识别的二维码可直接点击。外部链接会在新标签页打开。Google Drive、问卷等目标页面是否需要登录，由相应服务自行决定。

## 分享与下载

点击底部 **共有**，查看该期二维码和固定链接。点击 **リンクをコピー** 复制链接；复制成功后不弹提示。无法自动复制时，可手动选中窗口内的 URL 复制。

点击 **PDF** 在新标签页打开原文件，再使用浏览器或设备的保存功能。所有已公开期刊均可阅读、保存和转发。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 找不到底部按钮 | 鼠标移到下沿，或在手机上点击下沿 |
| 找不到缩略图和目录 | 鼠标移到左边缘中部，或在手机上点击该位置 |
| 仍显示旧界面或旧图片 | 刷新页面；必要时换一个浏览器打开 |
| 空白、缺图或加载失败 | 检查网络后刷新，仍失败时联系发布人员 |
| 提示找不到该期 | 检查收到的链接，向发布人员索取正确链接 |

反馈时请附上 **期号、页码、设备与浏览器名称、错误提示**。
