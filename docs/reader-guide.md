# 関西通信 ご利用ガイド

[最新号を読む](https://longxy4.github.io/kansai-magazine/) · [バックナンバー](../README.md#バックナンバー) · [中文](reader-guide.zh-CN.md)

## 読み始める

共有された号のリンク、または QR コードを開いてください。アプリのインストールやログインは不要です。パソコンは見開き表示、スマートフォンの縦画面は単ページ表示になります。

## ページをめくる・移動する

| 操作 | パソコン | スマートフォン |
| --- | --- | --- |
| 次・前のページ | ページをクリック、左右キー、下部の ‹ / › | 等倍で左右端をタップ、左右にスワイプ、下部の ‹ / › |
| 下部の操作バーを出す | マウスを画面の下端へ移動 | 画面の下端をタップ |
| ページ番号で移動 | 下部の番号を入力し Enter | 下部の番号を入力して確定 |
| ページ一覧を開く | マウスを左端へ移動 | 左端の中央付近をタップ |

下部の「現在のページ / 総ページ数」で位置を確認できます。ページ番号は表紙を含むため、誌面に印刷された番号と異なる場合があります。

左側の **ページ** は縮小画像の一覧、**目次** は記事名の一覧です。選ぶとそのページへ移動します。左側の一覧は通常非表示です。閉じるときは ×、または誌面を選んでください。

## 拡大して読む

下部のスライダーで **1〜3 倍** に拡大できます。パソコンでは **Ctrl＋マウスホイール**、キーボードの **＋ / －** も使えます。拡大中は誌面をドラッグして表示位置を移動します。ページを移動すると拡大は解除されます。

スマートフォンでは**2本指のピンチ操作で拡大・縮小**でき、**本文のダブルタップで2倍／等倍に切り替え**られます。拡大中は1本指で誌面を動かし、ページはめくれません。指を閉じる、再度ダブルタップする、または下部の倍率表示を押すと等倍に戻せます。拡大中も画面下端のタップで操作バーが開きます。リンク・QRコードはシングルタップで移動します。

全画面アイコンで全画面表示に切り替えます。対応していないブラウザでは、通常表示のまま利用してください。

## 誌面のリンク・QR コード

目次、誌面に埋め込まれたリンク、読み取り済みの QR コードは直接選べます。別サイトへのリンクは新しいタブで開きます。移動先のログインや閲覧権限は、そのサービスの設定によります。

## 共有・PDF

下部の **共有** を押すと、その号の QR コードと固定リンクが表示されます。**リンクをコピー** を押して共有してください。コピー成功の通知は表示しません。コピーできない場合は、表示された URL を選んで手動でコピーできます。

**PDF** から元の PDF を別タブで開けます。端末・ブラウザの機能で保存できます。公開されている号は誰でも閲覧・保存・転送できます。

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 操作バーが見えない | パソコンは下端へマウスを移動、スマートフォンは下端をタップ |
| ページ一覧が見えない | 左端中央へマウスを移動、またはタップ |
| 古い画面・画像のまま | ページを再読み込み。改善しなければ別のブラウザで開く |
| 表示されない・画像が欠ける | 通信状態を確認して再読み込み。改善しなければ発行担当者へ連絡 |
| 「指定された号が見つかりません」 | 共有リンクを確認し、発行担当者から正しいリンクを受け取る |

問い合わせるときは、**号名、ページ番号、端末・ブラウザ名、表示されたメッセージ**を添えてください。
